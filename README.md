# Project 1 - Wordle

Submitted by: **Nevyn Brown**

**Wordle** is an iOS word-guessing game where players have six attempts to identify a randomly selected five-letter word. Each completed guess receives color-coded feedback for correct letters, misplaced letters, and incorrect letters.

Time spent: **2** hours spent in total

## Required Features

The following **required** functionality is completed:

- [x] App displays a keyboard on the screen
- [x] When tapping on the keyboard, a letter is shown or deleted (letter selected)
- [x] User can play a basic version of Wordle, with different goal words each time

The following **optional** features are implemented:

- [ ] Improve and customize the user interface by adding a launch screen and app icon
- [ ] Run the app on a device rather than in the simulator

The following **additional** features are implemented:

- [x] Letter tiles animate when a letter is entered
- [x] Completed guesses display color-coded feedback
